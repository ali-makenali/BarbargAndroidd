پروژه Android Studio - دستیار باربرگ شهری

روش ساخت APK:
1) Android Studio را نصب و باز کنید.
2) گزینه Open را بزنید و پوشه BarbargAndroidProject را انتخاب کنید.
3) صبر کنید Gradle Sync کامل شود.
4) از منو:
   Build > Build APK(s)
5) فایل APK معمولاً در مسیر:
   app/build/outputs/apk/debug/app-debug.apk
ساخته می‌شود.

این برنامه اطلاعات را روی همان دستگاه ذخیره می‌کند و برای مدیریت حمل واقعی طراحی شده است.
